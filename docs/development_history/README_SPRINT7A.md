# Sprint 7A — World State Foundation

Creates the persistent initial state of the synthetic retail world.

Default output:
- 10 stores
- 100 SKUs
- 8 suppliers
- 1,000 store/SKU inventory positions
- reorder points, safety stocks and target stocks
- initial financial ledger

Run `INSTALL_SPRINT7A.ps1`, then `RUN_SPRINT7A.ps1`.

Outputs are written to `simulation/output/world/`.
